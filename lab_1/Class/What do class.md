<h1> Что делают Классы </h1>
Классы:
- Classification
- generalizing_ability
- kernel
- load_data
- Paint_data
- logs


<h2> Classification</h2>
В данном файле реализован KNN с весами и без них. Это метод ближайших соседей.
Сам этот метод находит метку класса в зависимости от его соседей.

<h2> Generalizing ability</h2>

В данном файле реализована проверка обобщающей способности алгоритма (пока только KNN). Здесь был реализован метод LOO. В данном методе мы поочерёдно выкидываем 1 объект из выборки и проводим Классификацию. И этот метод возвращает количество ошибок алгоритма.

<h2> kernel</h2>

В данном файле реализовано ядро для алгоритмов. Здесь был реализовано ядро Епанечникова. Эта функция принимает число и выдаёт вес для числа. Так же в этом файле есть евклидово расстояние.


<h2> load_data</h2>
В данном файле реализована загрузка датасета.

<h2> Paint_data</h2>
В данном файле реализованы отрисовка графиков. В этом файле есть показ датасета.
Так же в этом файле есть отрисовка графика LOO ошибок, где по оси х идёт размер k.
Ещё в этой есть отрисовка классов.

<h2> logs</h2>
Файл в котором происходит запись в файл ошибок.
